# 03 - UNIDADE 2 - RECUPERAÇÃO DE INFORMAÇÃO COM BASE NO CONTEÚDO VISUAL

[← Voltar à disciplina](../README.md)

## Resumo da unidade

A unidade constrói busca visual por conteúdo. Descritores transformam imagens ou quadros em vetores, e uma medida de distância permite recuperar itens semelhantes.

### Exemplo

Em busca de cenas, extraia descritores de cada quadro, crie um vocabulário visual e compare a consulta com o índice em vez de percorrer vídeos brutos.
