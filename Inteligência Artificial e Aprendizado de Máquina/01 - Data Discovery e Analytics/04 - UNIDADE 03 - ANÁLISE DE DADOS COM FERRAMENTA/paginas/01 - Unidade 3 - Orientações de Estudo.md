**ANÁLISE DE DADOS COM FERRAMENTA**

Nesta Unidade 3, vamos falar sobre a importância de conhecer a base de dados que será utilizada nas análises. Criar por criar dashboard, não trás nenhum benefício, tanto para você profissional da área, mas principalmente para o usuário algo que gere valor.

Neste cenário vamos usar análises com a ferramenta Tableau e para não ficar muito repetitivo, um pouco com o Power BI. 

---

**Temáticas da unidade**

- Estudo de base de dados
- Análises com ferramentas.

---

**Objetivos**

- Compreender a importância de estudar uma base de dados;
- Conhecer e desenvolver análises de dados em duas ferramentas líderes de mercado
  - Tableau
  - Power Bi

Observação: você como aluno pode solicitar uma chave de acesso ao Tableau através do link: [Tableau para Estudantes](https://www.tableau.com/pt-br/academic/students#form)
