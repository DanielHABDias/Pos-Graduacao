# 04 - Python para Ciência de Dados

## Resumo da disciplina

Usar Python e seu ecossistema científico para representar, transformar, analisar e visualizar dados.

A disciplina avança pelos seguintes eixos: fundamentos da linguagem, NumPy e vetorização, pandas e manipulação de dados, visualização e notebooks reprodutíveis.

## Objetivos de aprendizagem

- Compreender e aplicar fundamentos da linguagem.
- Compreender e aplicar NumPy e vetorização.
- Compreender e aplicar pandas e manipulação de dados.
- Compreender e aplicar visualização e notebooks reprodutíveis.

1. Comece pelas páginas de cada unidade para formar o mapa conceitual.
2. Use os PDFs como fonte principal e as apresentações como revisão visual.

4. Registre dúvidas e conecte os conceitos às disciplinas anteriores.
5. Termine cada unidade produzindo uma explicação própria e um exemplo prático.
