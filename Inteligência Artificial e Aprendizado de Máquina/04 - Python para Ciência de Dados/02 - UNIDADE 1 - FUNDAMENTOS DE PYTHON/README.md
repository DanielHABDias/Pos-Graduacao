## Resumo da unidade

A unidade cobre os elementos básicos de Python: valores, coleções, decisões, repetições e funções. A escolha da estrutura de dados afeta clareza e custo das operações.

### Exemplo

Use uma lista para uma sequência ordenada, um conjunto para testar pertencimento sem duplicidade e um dicionário para associar chaves a valores.
