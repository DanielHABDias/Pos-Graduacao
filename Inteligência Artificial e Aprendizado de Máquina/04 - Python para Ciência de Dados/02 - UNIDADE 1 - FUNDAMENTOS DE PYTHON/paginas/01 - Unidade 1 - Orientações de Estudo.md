- Relembrar conceitos básicos e importantes de programação utilizando a linguagem Python. Esses conceitos são: tipos de dados, regras para criação de identificadores, declaração de variáveis, comentários e type casting.

  - Listas
  - Tuplas
  - Dicionários
  - Conjuntos
