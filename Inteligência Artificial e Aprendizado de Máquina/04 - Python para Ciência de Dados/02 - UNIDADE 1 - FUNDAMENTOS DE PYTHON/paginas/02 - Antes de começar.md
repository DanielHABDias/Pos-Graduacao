**Objetivos:**  

• Sugerir a instalação do Anaconda.  
• Introduzir o uso do Jupyter Notebook.

**ATENÇÃO!!!** Antes de assistir o primeiro vídeo, é importante que você instale o ANACONDA, uma distribuição gratuita que agrega o Python, Jupyter Notebook, o IDE Spyder e bibliotecas muito utilizadas no Python como Pandas, Numpy e Scikit-learn, em um único instalador. O Anaconda está disponível para Windows, MacOS e Linux. Escolha a versão mais nova do Python ao escolher o instalador a ser baixado (sugiro a versão 3.7). O Anaconda pode ser baixado nesse [link](https://www.anaconda.com/download).
