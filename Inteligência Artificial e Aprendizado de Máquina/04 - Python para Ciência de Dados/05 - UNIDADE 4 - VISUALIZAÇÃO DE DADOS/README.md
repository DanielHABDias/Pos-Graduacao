## Resumo da unidade

A unidade trata visualização como parte da análise. O gráfico deve corresponder ao tipo de variável e à comparação desejada, com escalas e rótulos que não distorçam a leitura.

### Exemplo

Use barras para comparar categorias, linhas para evolução temporal e dispersão para investigar relação entre duas variáveis quantitativas.
