## Resumo da unidade

A unidade introduz arrays NumPy e vetorização. Operações sobre arrays evitam laços explícitos, deixam a intenção matemática mais clara e aproveitam implementações otimizadas.

### Exemplo

Para normalizar uma coluna, subtraia a média do array inteiro e divida pelo desvio padrão, em vez de atualizar elemento por elemento.
