**UNIDADE:** PUC Minas Virtual

---

#### **OBJETIVOS**

- Ser capaz de entender e manipular as principais estruturas de dados em Python;
- Compreender e aplicar a vetorização em Python através da biblioteca Numpy;
- Ser capaz de fazer análises de dados através da biblioteca Pandas e visualizações através da biblioteca Matplotlib.

---

#### **MÉTODOS**

Os métodos de ensino adotados são:

- Videoaulas
- Notas de aula (slides)
- Atividades objetivas
- Fórum de discussão

 Você deve assistir a todas as videoaulas e realizar as atividades e leituras indicadas.

#### **EMENTA**

Fundamentos da Linguagem Python. Vetorização. Bibliotecas para manipulação dados. Bibliotecas para visualização de dados.

#### **UNIDADES DE ENSINO/ CONTEÚDO PROGRAMÁTICO**

- Unidade I - Fundamentos de Python
- Unidade II - Vetorização
- Unidade III - Manipulação de Dados
- Unidade IV - Visualização de Dados
