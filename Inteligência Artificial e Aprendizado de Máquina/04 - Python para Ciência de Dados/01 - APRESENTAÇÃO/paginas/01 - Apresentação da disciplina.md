**PYTHON PARA CIÊNCIA DE DADOS**

Olá, seja bem-vindo(a)!

É um prazer tê-lo como nosso aluno da disciplina **Python para Ciência de Dados**. Esperamos que possa aproveitar ao máximo todos os conteúdos que preparamos para você alcançar seus objetivos neste processo de aprendizagem. 

Esta disciplina apresenta uma introdução a uma das principais linguagens utilizadas por profissionais das áreas de Machine Learning e Data Science: a linguagens Python.  Esperamos que você possa aproveitar ao máximo todos os conteúdos que preparamos para você alcançar seus objetivos neste processo de aprendizagem. Os conteúdos dessa disciplina foram divididos em quatro unidades. Para acessar os conteúdos, clique no link do tema desejado.

**Ao finalizar os estudos, você deverá ser capaz de:**

- Ser capaz de entender e manipular as principais estruturas de dados em Python
- Compreender e aplicar a vetorização em Python através da biblioteca Numpy
- Ser capaz de fazer análises de dados através da biblioteca Pandas e fazer visualizações através de bibliotecas como a Matplotlib.
