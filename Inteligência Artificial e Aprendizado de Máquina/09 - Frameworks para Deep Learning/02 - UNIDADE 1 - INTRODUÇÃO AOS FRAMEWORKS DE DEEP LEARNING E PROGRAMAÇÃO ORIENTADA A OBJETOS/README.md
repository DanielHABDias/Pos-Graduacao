## Resumo da unidade

A unidade apresenta frameworks de deep learning e usa orientação a objetos para organizar dados, modelos e treinamento. Separar responsabilidades facilita teste e troca de componentes.

### Exemplo

Uma classe de modelo define a arquitetura. O laço de treinamento recebe lotes, calcula perda, propaga gradientes e atualiza parâmetros.
