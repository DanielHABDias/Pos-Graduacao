## Resumo da unidade

A unidade detalha ETL: extrair sem perder a origem, transformar com regras verificáveis e carregar no destino com controle de falhas. As práticas usam arquivos, SQL Server e Power BI.

### Exemplo

Uma carga incremental deve identificar registros novos ou alterados e ser idempotente, para que uma repetição não duplique dados.
