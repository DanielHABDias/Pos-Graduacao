## Resumo da unidade

A unidade conecta dado, informação, conhecimento, BI e governança. Governança define responsabilidades, significado, qualidade, segurança e uso permitido dos dados.

### Exemplo

Um campo chamado `cliente_ativo` precisa de definição, responsável, regra de atualização e tratamento conhecido para valores ausentes.
